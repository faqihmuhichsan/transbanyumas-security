# 📖 Panduan Penggunaan - Security Patrol System

## Untuk Petugas Security

### 1. Login
1. Buka aplikasi di browser HP
2. Masukkan **Username** dan **Password** yang diberikan Super Admin
3. Tekan tombol **MASUK**

### 2. Memulai Patroli
1. Di halaman **Home**, pilih area yang akan dipatroli (Koridor I-IV atau Kantor Pusat)
2. Pilih **Shift** (Pagi / Malam)
3. Isi form laporan:
   - 📷 **Ambil foto** kondisi lokasi (wajib)
   - 📍 **Titik pengecekan** — ketik nama lokasi (Pos Jaga, Pompa Air, dll)
   - 📍 **GPS** — tekan tombol untuk bukti lokasi
   - ✅ **Checklist** item yang dicek
   - 📝 **Status** (Aman / Temuan) dan **catatan**
4. Tekan **KIRIM LAPORAN**
5. Share ke WhatsApp jika perlu

### 3. Melihat Riwayat
- Tab **Riwayat** menampilkan semua laporan yang sudah kamu kirim
- Bisa search, filter, dan lihat detail

### 4. Rekap Bulanan
- Tab **Rekap** menampilkan ringkasan per bulan
- Bisa share ke WhatsApp per shift

## Untuk Super Admin

### 1. Login
1. Buka aplikasi, login dengan akun Super Admin
2. Otomatis diarahkan ke halaman Admin Panel

### 2. Dashboard
- Lihat ringkasan: total security, laporan hari ini, temuan
- Akses cepat ke semua fitur

### 3. Kelola User
1. Buka menu **Kelola User**
2. **Tambah User Baru**: Klik tombol "+ Tambah User"
   - Isi: Username, Password, Nama Lengkap, Role, No HP, Koridor
3. **Edit User**: Klik tombol Edit di baris user
4. **Reset Password**: Klik tombol Reset di baris user
5. **Nonaktifkan**: Klik toggle Aktif/Nonaktif

### 4. Lihat Semua Laporan
- Filter berdasarkan: tanggal, koridor, shift, status, petugas
- Klik laporan untuk detail lengkap
- Export ke CSV

### 5. Statistik
- Pilih bulan untuk rekap bulanan
- Lihat statistik per koridor dan per petugas

### 6. Audit Log
- Semua aktivitas tercatat: login, buat/hapus laporan, kelola user
- Filter berdasarkan tanggal, user, dan jenis aksi

## Tips & Troubleshooting

### Kamera tidak bisa dibuka?
- Pastikan izin kamera sudah diberikan di browser
- Coba gunakan opsi **GALERI** untuk upload dari file

### GPS gagal?
- Aktifkan **Lokasi/GPS** di pengaturan HP
- Coba di luar ruangan untuk sinyal lebih baik
- Jika tetap gagal, tekan **Lewati GPS** (laporan tetap bisa dikirim)

### Lupa Password?
- Hubungi Super Admin untuk reset password

### Aplikasi lambat?
- Pastikan koneksi internet stabil
- Foto otomatis di-compress agar ringan
